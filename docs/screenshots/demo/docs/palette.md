# Lumen UI palette

The brand blue is `#2662ea`; hover states darken it to `#1d4ed8`.

| Token | Value | Use |
| --- | --- | --- |
| Primary | `#2563eb` | Buttons, links |
| Accent | `oklch(70% 0.19 330)` | Highlights |
| Success | `rgb(22, 163, 74)` | Confirmations |
| Warning | `hsl(38 92% 50%)` | Warnings |
| Danger | `#dc2626` | Errors, destructive actions |

Surfaces: `#0f172a` for the page, `#1e293b` for cards and `#334155` for borders.

```yaml
chart: ["#2563eb", "#16a34a", "#f59e0b", "#dc2626", "#9333ea"]
```
